v1 scope: independent two-group comparisons only, using standard FreeSurfer tabular .stats files (subcortical/global volumes, cortical parcellation across the DKT/Desikan/Destrieux atlases, cerebellum, hypothalamus, white-matter parcellation, Brodmann areas, w-g.pct). curv.stats and corpus-callosum JSON files are not parsed in this version. Sample-size formulas use a normal (z) approximation and a t-distribution-adjusted iterative estimate (Cornish–Fisher approximation for small pilot N) — treat the t-adjusted number as the more conservative estimate for small pilot cohorts.
