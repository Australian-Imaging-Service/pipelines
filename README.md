# AIS Analysis Pipelines

AIS Analysis pipelines is a collection of scripts for generating containerised
pipelines that can be run by the XNAT Container Service plugin.

Documentation is in [`docs/`](docs), organised by who it is for and published on the
[AIS website](https://australian-imaging-service.github.io):

- [Pipeline users](docs/users): running pipelines and using their results
- [Pipeline developers](docs/developers): building, contributing and releasing pipelines
- [ICT research support](docs/ict): deploying and operating pipelines on a node

Each section follows [Diátaxis](https://diataxis.fr): tutorials, how-to guides,
reference and explanation. Design records that are not published are in [`design/`](design).
