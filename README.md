# AIS Analysis Pipelines

AIS Analysis pipelines is a collection of scripts for generating containerised
pipelines that can be run by the XNAT Container Service plugin.

See [Releasing pipelines](docs/releasing-pipelines.md) for the release catalogue and
publication process.
See [Pipeline naming](docs/pipeline-naming.md) for how pipelines are organised and
named.
