## Documentation points

- Where to find a pipeline's Zenodo record and reference for the version used.
- How to cite that version and credit upstream software where appropriate.
- What the record provides: authors, licence, description, spec, source and image reference.
- Production references are the intended goal; Sandbox DOIs are not production citations.
